# LOW-KEY footwear

Original footwear concept storefront with LK-007 sole comparison and LK-009 color selection.

Live site: https://abduallahqobaisy.github.io/low-key-footwear/

Serve locally with `python3 -m http.server 4173`. All asset paths are relative for GitHub project Pages.

This is a fictional demonstration store. No payment or real order processing is connected. Supplied brand emblem and waterfront campaign are used in the current design.
